# Repository Layout & Monorepo Structure

The **Personal Learning Ground** repository is organized as a clean, cohesive monorepo housing both the React frontend and the Hono Node.js backend alongside comprehensive documentation, test suites, and operational scripts.

---

## 🎯 Key Directory Responsibilities

### `frontend/`
- Contains all browser-executed code.
- Builds static output to `dist/client/`.
- Uses same-origin routing (`/api/*`) via Vercel proxy configuration.
- Governed by strict viewport requirements for laptop and iPad landscape displays.

### `server/`
- Contains authoritative business logic, database transactions, and grading algorithms.
- Enforces strict security boundaries (sessions, parent verification, rate limits).
- Directly interfaces with Neon PostgreSQL via Drizzle ORM.
- Owns all achievement evaluations and reward distributions.

### `docs/`
- The architectural record of truth.
- Contains historical transition notes, ADRs, design specifications for minigames, and database migration manifests.

### `scripts/`
- Operational tooling for running local UAT (`scripts/start-uat.sh`) and enforcing zero-artifact commits (`scripts/check-generated-artifacts.sh`).
